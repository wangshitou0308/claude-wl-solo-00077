# 燕尾补齿放样与试装台

面向旧抽屉燕尾榫的纯前端修复辅助工具。它只针对**残存榫列中的单个缺口补齿**，不会生成重切完整榫齿或重建整列榫的方案。

## 本机运行

```bash
npm install
npm run dev
```

打开 Vite 输出的本机地址（默认 `http://localhost:5173/`）。生产构建：

```bash
npm run build
npm run preview
```

无需服务器后端；项目数据保存在浏览器 IndexedDB 中。

## 工作流程

1. 在毫米 SVG 标尺中描出：
   - 原板/板厚轮廓；
   - 残存榫肩两点；
   - 缺口范围；
   - 裂纹禁切区；
   - 相邻完整榫齿等不可碰撞区。
2. 登记木纹方向、锯路宽、测量误差、凿刀可达侧、目标胶缝、允许肩缝和侧隙。
3. 程序按最不利边界计算：
   - 缺口按测量误差内缩，代表“确定可切割”的旧件区域；
   - 裂纹和完整榫齿外扩误差与胶缝；
   - 最终补齿和修凿区域必须完全留在确定损伤区内；
   - 补齿木纹与原板同向；
   - 沿木纹插入时，扫掠路径不得碰完整榫齿。
4. 多套可行解并列显示；卡片列出尺寸、肩缝、侧隙、裂纹净距、插入净距和可达侧。
5. 当多个方案难以区分时，顶部提示下一处最有区分力的测量。
6. 选定后依次高亮：保守放样 → 留量锯切 → 修凿 → 干装。
7. 干装时回报顶住、露肩、肩缝或侧隙：
   - 顶住：齿尖截短；未完成步骤失效，旧粗锯坯在仍有加工余量时保留；
   - 露肩/肩缝：根端长度重算；
   - 侧隙：补齿放大或提示贴薄片/换新坯，相关锯切失效。
8. 误确认步骤或误报试装现象均可撤回；测量或尺寸变化会使旧轮廓对应步骤失效。
9. 打印时只显示 1:1 样板和 50 mm 校准标尺。浏览器打印必须选择 **100% / 实际大小**，关闭“适应页面”，并先用标尺校准。

## 重要工艺限制

- 绿色实线是最终补齿；绿色虚线是粗锯/干装阶段的加大坯料轮廓。
- 旧件上的锯口若不能完全落在误差内缩后的缺口内，会标成“禁锯”，应只修凿或补测边界。
- 坯料矩形上的锯切是独立木料加工，不作为旧件切割许可。
- 本工具不能替代实体安全判断：腐朽、松动、裂纹贯穿或榫列多点失效时，应改用更保守的结构修复方案。

## 代码结构

- `src/lib/geometry.ts`：凸包、内缩/外扩、相交、净距和扫掠碰撞等几何工具。
- `src/lib/engine.ts`：误差边界、候选补齿、坯料、锯路、修凿区、试装反馈重算。
- `src/lib/db.ts`：IndexedDB 持久化。
- `src/components/MeasurementEditor.tsx`：毫米标尺 SVG 描绘与拖点编辑。
- `src/components/CandidateList.tsx`：并列候选和下一步测量提示。
- `src/components/WorkflowPanel.tsx`：步骤确认、撤回、试装反馈。
- `src/components/PrintTemplate.tsx`：1:1 打印样板。
